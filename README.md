## QR Code Frontend

A simple and responsive QR Code frontend project built using HTML and CSS. This project displays a QR code inside a clean card layout with modern styling and hover effects.

# 🚀 Features
Clean and modern user interface
Responsive design for mobile and desktop
QR code display
Centered card layout
Rounded corners and box shadow
Smooth hover animation
Mobile-friendly layout
# 🛠️ Technologies Used
